# AI PHOTO VIDEO (Android)

An Android photo-to-video editor starter app.

## Features
- Pick a photo from the device
- Add a text caption and preview it over the photo
- Export a 5-second MP4 video to the app's Movies folder
- GitHub Actions builds a debug APK

## Build
Open this repository in Android Studio, or run the **Build Android APK** workflow from the Actions tab. Download the `app-debug.apk` artifact from the successful workflow run.

## Current scope
This first version is an offline editor. AI image generation and AI photo animation require an external provider API key and backend; they are not falsely presented as active features yet.
